###  PROJECT NAME :Advance Event Management API ###

### discription

It is a robust backend api which helps to manage event management platform with the help of multiple endpoints


### run cammand
npm start or node index.js

### Endpoints

1.  POST 'api/events' : accepts the { eventName,date , location , description } to the request body
2. GET 'api/events' : returns all the events in JSON
3. PUT 'api/events/:id : it will update the data by id
4. DELETE 'api/events/:id : user can delete the data
